ゲーム・レベルデザイン講座 ／ Part 2：ゲーム空間の設計

Unit 3：空間構造とマップ設計

主軸：空間 担当変数：空間構造の型（直線型／分岐型／ハブ型／ループ型の接続方式）

この Unit の学習目標

  • 空間構造の4つの型（直線型／分岐型／ハブ型／ループ型）を、模式図で見分けて説明できる
  • 同じ広さ・同じ部屋数でも、接続方式で体験が変わることを具体例で説明できる
  • させたい体験から逆算して、構造を選ぶ考え方を説明できる

Unit 1・2 では「体験」そのものを分解してきました。では、その体験はどこで起きるのでしょう。答えは「空間の中」。Part 2 では空間の設計に入ります。最初のテーマは、マップの一番大きな骨格——「構造」です。

この Unit の担当は「構造そのもの」（場所どうしのつながり方）。 構造の中でどう誘導するか（光・視線・手がかり）は Unit 4、空間にどう意味を持たせるか（密度や環境の物語）は Unit 5 で扱います。

1. 体験は「空間」の中で起きる

プレイヤーは、場所にいて、場所から場所へ移動しながら遊びます。判断も感情も、空間の上での出来事です。だから空間の作り方は、そのまま体験の作り方になります。

この Unit で見るのは、その中でも一番大きな決め方——マップ全体の「構造」です。キーワードは1つだけ。同じ広さ・同じ部屋数でも、つなぎ方で体験は変わる。

たとえば部屋が4つあるマップ。一本道につなぐか、輪につなぐかで、迷い方も、選ぶ楽しさも、安心感も違ってきます。部屋の中身は同じなのに、です。

2. マップは「場所」と「つながり」でできている

マップを思いきり単純化すると、「場所」と「つながり」の2つに分解できます。部屋の形や広さはいったん脇に置いて、「どこが、どこにつながっているか」だけを見る見方です。

この Unit で変えるのは「つながり方」だけです。部屋の中の敵や報酬の配置は Unit 7・8、誘導の手がかりは Unit 4 の担当。変数を1つに絞ることで、構造そのものの効果を見ます。

代表的なつながり方は4つ。直線型・分岐型・ハブ型・ループ型——順に見ていきましょう。なお、この4分類は本教材での整理のしかたで、実際のゲームでは組み合わせて使われることも多いものです。

3. 直線型：一列につなぐ

場所が一列につながり、決まった順番に進む構造です。

  • 体験：迷わない。物語や操作を、設計した順番どおりに見せられる（「教える→試す→応用する」と相性が良い）
  • 向く場面：ストーリーを順に追わせたいとき、新しい操作を段階的に覚えさせたいとき
  • 注意点：寄り道や発見の余地は小さい。一本道が長く続くと、「自分で進んでいる」より「運ばれている」感覚になりやすい

4. 分岐型：分かれて、合流する

途中で経路が分かれ、選んだ先で再び合流する構造です。

  • 体験：途中で「どちらに行くか」を選べる。選ぶ楽しさと主体感が生まれ、選ばなかった側への好奇心が残る
  • 向く場面：安全な遠回りと危険な近道など、リスクの違う道を選ばせたいとき
  • 注意点：両方の道を作る手間がかかる。片方しか通らないプレイヤーもいるので、大事な情報は合流した後に置くなどの配慮が要る

5. ハブ型：中心に戻ってくる

中心の場所（ハブ）から放射状につながり、行き来のたびに中心へ戻る構造です。

  • 体験：中心が拠点になり、「帰ってこられる」安心感と、現在地の分かりやすさが生まれる。行き先は自分で選べる
  • 向く場面：拠点で準備をして各地へ出かけるRPGのワールドなど、同じ場所に何度も戻る設計
  • 注意点：中心への往復が「作業」になりやすい。中心の場所自体に変化や情報がないと、移動の時間が退屈になりがち

6. ループ型：輪につなぐ

場所が輪のようにつながり、一周したり逆回りしたりできる構造です。

  • 体験：行き止まりがないので探索が止まらない。一周すると全体像がつかめ、「近道」の発見も生まれる
  • 向く場面：探索が中心のマップ、ぐるぐる回るうちに道を覚えさせたいマップ
  • 注意点：目的地への最短の道が分かりにくいと、ただ回らされている感覚にもなる。目印などの誘導（Unit 4）とセットで考えたい構造

7. 比べてみよう：同じ部屋、4つのつなぎ方

同じ5つの場所（スタート・部屋A・広場・部屋B・ゴール）を、4つの構造でつなぎ替えてみます。場所の位置も数も同じ。違うのはつながりだけです。

構造進み方迷いやすさ得意な体験
直線型順番どおりに一本道低い物語・学習を順に見せる
分岐型選んで進み、合流する中くらい選択と主体感
ハブ型中心に戻りながら放射状中くらい（中心が目印になる）拠点の安心感
ループ型一周できる・逆回り可低〜中くらい探索と近道の発見

表はあくまで傾向です。実際の迷いやすさは、目印や手がかりの置き方（Unit 4）でも大きく変わります。

8. 構造選びは、体験選び

4つの型に、優劣はありません。あるのは「何を得て、何を手放すか」のトレードオフです。

だから選ぶときは、形からではなく「プレイヤーにどう感じてほしいか」から逆算します。順番に見せたいなら直線型、選ばせたいなら分岐型、拠点の安心感ならハブ型、探索させたいならループ型——体験が先、構造は後です。

実際のゲームでは組み合わせも普通です（町はハブ型、その先のダンジョンは分岐型、など）。型は「全体を1つに決めるもの」ではなく、場所ごとに使い分ける道具でもあります。

次の Unit 4 では、決めた構造の中でプレイヤーをどう誘導するか——光や視線といった「情報」の設計に進みます。

用語メモ

Node ノード（場所）
意味：構造を模式化したときの「場所」の単位。部屋・広場などを、形や広さを脇に置いて「点」として扱う。
具体例：マップを「場所A—場所B」のつながりだけで描き直す。
Linear 直線型（リニア）
意味：場所が一列につながり、決まった順番に進む構造。
具体例：部屋を順に進み、最後にボス部屋がある一本道のステージ。
Branching 分岐型
意味：途中で経路が分かれ、選んだ先で再び合流する構造。
具体例：安全な遠回りと危険な近道を選べる洞窟。
Hub-and-Spoke ハブ型（ハブ・アンド・スポーク）
意味：中心の場所から放射状につながり、行き来のたびに中心へ戻る構造。
具体例：拠点の町から各地へ出かけ、町に戻ってくるRPGのワールド。
Loop ループ型
意味：場所が輪のようにつながり、一周したり逆回りしたりできる構造。
具体例：環状の通路を一周でき、回るうちに近道が見つかるマップ。
Landmark ランドマーク（目印）
意味：遠くからでも見え、自分の位置や方角を把握する助けになる目立つ構造物。
具体例：マップ中央の大きな塔。迷っても塔を見れば方角が分かる。
