# ゲーム・レベルデザイン講座

ゲーム開発を学ぶ学生を対象とした、レベルデザインの理論と実践を学習するための教育教材です。

単にマップやステージを作る方法を教えるのではなく、ゲームの仕組みを活用して、プレイヤーの行動、判断、感情、学習、達成感を設計する技術としてレベルデザインを扱います。

**中心となる定義：**

> レベルデザインとは、プレイヤーの体験を設計することである

## カリキュラム概要

全12 Unit / 5 Part 構成：

- Part 1：レベルデザインの基礎
- Part 2：ゲーム空間の設計
- Part 3：難易度とゲームプレイの設計
- Part 4：時間・感情・テンポの設計
- Part 5：制作と検証

レベルデザインを、空間・時間・情報・挑戦・感情の5つの軸から分析します（この5軸は本教材独自の整理です）。

## 最終的な教育目標

学生が、レベルを「なんとなく配置して作る」段階から、「意図したプレイヤー体験を実現するために設計し、検証し、改善する」段階へ進むこと。
